# Atividade-03---Construtores-e-Encapsulamento

Implemente a classe Personagem de forma que outras partes do programa possam consultar ou modificar apenas aquilo que fizer sentido de acordo com as regras acima.

Depois, crie uma classe Main e teste seu personagem realizando diferentes ações durante uma pequena aventura.

Por exemplo:

Crie um personagem.

Faça o personagem receber dano.

Recupere parte de sua vida.

Faça o personagem encontrar algumas moedas.

Tente realizar uma compra.

Faça o personagem subir de nível.

Exiba seu estado final.
